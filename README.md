# 🍽️ Sabor Local

Aplicativo de delivery focado em culinária mineira, desenvolvido como projeto acadêmico.

## 📱 Funcionalidades

- Login e cadastro
- Listagem de produtos
- Carrinho de compras
- Pagamento
- Acompanhamento do pedido com mapa
- Perfil do usuário

## 🎨 Design

O design foi desenvolvido no Figma, com foco em UX e UI modernos.
